# 📝 To-Do List Web App

A simple, interactive To-Do List web application built with **HTML**, **CSS**, and **JavaScript**. Easily add, complete, and remove your daily tasks with a clean and responsive interface.

---

## 🚀 Features

- Add new tasks quickly
- Mark tasks as completed
- Remove tasks from the list
- Responsive design for mobile and desktop
- All data is currently stored in memory (no backend or localStorage yet)

---

## 📂 Project Structure

```
To-Do List/
├── index.html      # Main HTML file
├── style.css       # App styling
└── script.js       # App logic
```

---

## 🛠️ How to Run

1. Open the `To-Do List` folder.
2. Double-click `index.html` or open it in your web browser.
3. Start adding your tasks!

No installation or server required. All features work offline.
